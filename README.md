# Seth J Krasnianski

Personal portfolio site built with [Next.js](https://nextjs.org/), TypeScript, and Sass.

## Setup

Install [Nix](https://nixos.org/download/) and [direnv](https://direnv.net/), then enable the repository's development shell:

```bash
direnv allow
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run format:check
npm run build
```
